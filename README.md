# Astana Evening Events

Ежедневная вечерняя афиша Астаны в Telegram.

Каждый день в 19:00 по времени Алматы GitHub Actions формирует сообщение:

- 3–5 вариантов досуга;
- театральная афиша;
- киноафиша;
- краткий прогноз погоды;
- ссылки для проверки расписания и наличия мест.

## Настройка Telegram

В репозитории откройте **Settings → Secrets and variables → Actions → New repository secret** и добавьте:

- `TELEGRAM_BOT_TOKEN` — токен уже созданного Telegram-бота;
- `TELEGRAM_CHAT_ID` — идентификатор вашего личного чата или канала.

Значения можно взять из прежнего репозитория `news-digest`. Они не копируются между репозиториями автоматически.

## Проверка

Откройте **Actions → Astana evening events → Run workflow**.

Сначала включите `dry_run`: сообщение не отправится, но в журнале будет сформированный текст. После проверки запустите без `dry_run`, чтобы получить тестовое сообщение в Telegram.
