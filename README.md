# Astana Evening Events

Ежедневная афиша Астаны в Telegram.

Каждый день в 10:00 по времени Алматы GitHub Actions присылает одно сообщение с блоками:

- прогноз погоды на утро, день, вечер и ночь;
- театр;
- кино;
- конференции и IT-события;
- выставки и другие события.

У каждой карточки выводятся название, время, площадка, краткое описание и ссылка на исходную афишу. Если источник не указывает описание или точное время, бот прямо сообщает об этом и не добавляет догадки.

## Источники

- Театральная афиша: Teatr.kz;
- кино: Kinoafisha;
- конференции и IT: Astana Hub и Expomap;
- выставки и другие события: Astana.kz и Ticketon;
- прогноз: Open-Meteo.

## Настройка Telegram

В репозитории откройте **Settings → Secrets and variables → Actions → New repository secret** и добавьте:

- `TELEGRAM_BOT_TOKEN` - токен Telegram-бота;
- `TELEGRAM_CHAT_ID` - идентификатор личного чата или канала.

## Проверка

Откройте **Actions → Astana evening events → Run workflow**.

Сначала включите `dry_run`: сообщение не отправится, но сформированный текст будет виден в журнале. После проверки запустите workflow без `dry_run`, чтобы получить тестовое сообщение в Telegram.
